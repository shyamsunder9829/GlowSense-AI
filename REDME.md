# GlowSense AI ✨

AI-powered beauty analysis web app.

## Features
- Face scan & skin type detection
- Product recommendations
- Direct Amazon / Flipkart / Myntra links
- Contact form (MongoDB)
- Responsive UI with TailwindCSS
- MERN Stack

## Tech Stack
- React + TailwindCSS
- Node.js + Express
- MongoDB Atlas
- Framer Motion
